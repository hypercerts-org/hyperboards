# Hyperboards v1 (archived)

> [!IMPORTANT]
> This repository is archived and no longer maintained. It holds the first version of Hyperboards, built on Hypercerts v1 between 2023 and 2025, which showed hypercerts and their owners as boards. The current Hyperboards, at [hyperboards.org](https://www.hyperboards.org), is a separate app built on AT Protocol.

- Hypercerts has reached v2, and the v1 app has been retired. See [hypercerts.org/v1-retired](https://hypercerts.org/v1-retired).
- For Hypercerts v2, see [hypercerts.org](https://hypercerts.org) and the [documentation](https://docs.hypercerts.org).
